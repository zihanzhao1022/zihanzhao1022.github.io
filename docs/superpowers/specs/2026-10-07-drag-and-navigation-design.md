# 拖拽排序与导航编辑：设计文档

- 日期：2026-10-07
- 状态：设计已确认（用户选择"直接做并上线"）
- 基于：`2026-10-06-inline-edit-mode-design.md`、`2026-10-06-hide-items-design.md`

## 1. 目标

1. 编辑模式下，页面里的每条内容都可以拖拽排序。拖动时，卡片浮起来跟着鼠标走。
2. 编辑模式下，顶部导航栏可以新增、删除、隐藏、改名和排序。新增的可以是自定义页面，也可以是外部链接。

## 2. 拖拽排序

### 2.1 范围与分组

拖拽只在组内进行，跨组不能拖。

| 页面 | 分组 |
|---|---|
| 新闻（About） | 整个列表 |
| 经历 | 同一分类 |
| 论文 | 同一类型 + 同一年 |
| 项目 | 同一年（按时间里的第一个年份） |
| 奖项 | 同一年 |
| 报告 | 整个列表 |

- 组内顺序就是数据顺序。论文去掉"同一年内按等级排序"，改为按年份稳定排序。
- **迁移**：把 `content/publications.json` 按（年份降序、等级降序）稳定排序一次，让数据顺序等于当前的显示顺序，页面不变。测试用的 fixture 也做同样的迁移。
- 原来的"⇅ 排序"按钮、排序弹窗和 `EditRequest` 的 `reorder` 类型一并删除。

### 2.2 交互与外观

- **把手**：编辑模式下，每条内容左侧外边距里有一个拖拽把手（GripVertical 图标），垂直居中，位置是 `-left-6 sm:-left-8`。
- **操作方式**：鼠标按住把手移动 4px 后开始拖动。手机上把手设了 `touch-action: none`，可以直接拖。键盘也能操作：Tab 到把手，按空格拿起，方向键移动，空格放下。
- **悬浮效果**：
  - 被拖的条目在浮层（`DragOverlay`）里渲染，带 `shadow-2xl`、`ring-1 ring-purple-200`、`scale-[1.02]`、`-rotate-1`、`cursor-grabbing`；
  - 原位置变成同样大小的虚线占位框，其他条目平滑让位；
  - 松手后卡片以 200ms 动画落位。
- **加载方式**：只在编辑模式下加载拖拽代码。`SortableGroup` 放在主包，非编辑状态下渲染的 HTML 和原来的列表容器完全一样；编辑状态下才按需加载 `editor/dnd/SortableGroupImpl.tsx`。

### 2.3 保存

- **松手即保存**：
  1. 立即在页面上应用新顺序；
  2. 把 `reorder` 操作（只包含本组 id）放进保存队列，提交信息为 `content: reorder <集合>`。
- **保存队列**：EditorRoot 里的保存（弹窗保存和拖拽）都进同一个队列，一个接一个执行。每完成一项，就用 GitHub 返回的内容，叠加队列中还没执行的操作，作为页面内容。
- **失败处理**：拖拽保存失败时显示提示，并从 GitHub 重新读取最新内容，页面恢复为真实状态。
- **登录即将过期时**（剩余不足 15 分钟）：不执行拖拽，提示重新登录，和打开弹窗时的规则一致。

## 3. 导航栏

### 3.1 数据

新增 `content/navigation.json`，是一个导航项列表，顺序就是导航顺序：

```ts
type BuiltinPage = 'about' | 'experiences' | 'publications' | 'projects' | 'talks' | 'awards' | 'cv';
type NavItem =
  | { id: string; type: 'builtin'; page: BuiltinPage; label: string; hidden?: boolean }
  | { id: string; type: 'page'; label: string; slug: string; title: string; body: string; hidden?: boolean }
  | { id: string; type: 'link'; label: string; url: string; hidden?: boolean };
```

- **初始内容**：现有 6 项，外加 `{ id: 'cv', type: 'builtin', page: 'cv', label: 'cv', hidden: true }`。
- **作为一个集合**：`SiteContent` 增加 `navigation`，`ListCollection` 增加 `'navigation'`。编辑器加载内容时也读取它。
- **构建时剔除**：隐藏的导航项会被构建插件剔除，所以隐藏的自定义页面正文不会进入访客下载的代码。

### 3.2 路由与导航栏

- **路由**：按导航数据生成。
  - 首页 `/` 始终渲染 About，about 不能删除或隐藏；
  - 内置页面用固定路径（`/experiences` 等）；
  - 自定义页面的路径是 `/p/<slug>`；
  - 外部链接没有路由；
  - 其他地址显示 `NotFound`：内容加载完成后跳转首页，所有者的编辑器还在加载时什么都不渲染，免得过早跳走。
- **隐藏项**：访客既看不到也打不开。所有者登录后可以打开隐藏的页面；导航栏里只有在编辑模式开启时才显示隐藏项，半透明并带一个小眼睛图标。
- **导航栏渲染**：
  - 内置页面和自定义页面都用 `NavLink`，样式与现在一致；
  - 外部链接用 `<a target="_blank" rel="noreferrer">`，后面带一个小的外链图标；
  - 编辑模式下，末尾有"编辑导航"按钮，打开导航设置弹窗。
- **新增字段**：`EditModeValue` 增加 `ready`（访客始终为 true；所有者在编辑器加载完成前为 false）和 `reorder(collection, ids)`。

### 3.3 导航设置弹窗

- **每一行**：拖拽把手、名称、类型标签（首页 / 内置 / 自定义页面 / 外部链接，隐藏的再加"· 已隐藏"）、隐藏或取消隐藏、编辑、删除。首页没有隐藏和删除。
- **底部**："+ 新增页面"、"+ 新增外部链接"，以及"恢复已删除："后面列出不在导航里的内置页面。
- **保存**：
  - 每个操作立即保存，删除前需要确认；
  - 拖动行会调用 `reorder('navigation', ids)`；
  - 新增和恢复的项追加到导航末尾：`upsert` 操作增加可选参数 `at: 'start' | 'end'`，默认 `'start'`，导航用 `'end'`。
- **编辑和新增**：在这个弹窗上叠加打开 `ItemModal`。只有最上层的弹窗响应 Esc。

### 3.4 导航项表单

| 类型 | 字段 |
|---|---|
| 内置页面 | 导航名称* |
| 自定义页面 | 导航名称*、页面标题*、页面地址（slug，小写字母/数字/连字符，留空则由导航名称生成，再不行就用 id）、正文（Markdown，14 行） |
| 外部链接 | 导航名称*、网址*（必须以 http:// 或 https:// 开头） |

- 页面地址不能和其他自定义页面重复，否则在字段下提示"这个地址已被其他页面使用"。
- 首页那一项（about）只能改名，弹窗里没有隐藏和删除按钮。

### 3.5 自定义页面

- **布局**：和其他页面一致，标题 `h1` 是 `text-3xl font-light`，编辑模式下标题旁有铅笔，隐藏时还有"已隐藏"标签。
- **正文用新的块级渲染 `renderMarkdown`**：
  - `#` / `##` 渲染为 h2，`###` 渲染为 h3；
  - `- ` / `* ` 开头的行渲染为无序列表，`1. ` 开头的渲染为有序列表；
  - 单独一行的 `![说明](地址)` 渲染为图片，只接受 http(s) 和站内路径；
  - 空行分段，段内换行保留为 `<br />`；
  - 行内语法沿用 `renderInlineMarkdown`（链接、加粗），其余 HTML 一律转义。

## 4. 测试

- `editor/ops`：`upsert` 带 `at: 'end'` 时追加到末尾。
- `lib/markdown`：`renderMarkdown` 的标题、列表、段落换行、图片（含不安全地址）和转义。
- `lib/hiddenContent`：识别 `navigation.json`。
- `editor/schemas`：导航表单的网址和地址校验、由名称生成地址、`newItem` 按表单生成 id。
- `views/navigation.test.tsx`（用 MemoryRouter 渲染布局）：
  - 访客看到的导航顺序和名称正确，隐藏项不出现；
  - 外部链接在新标签页打开；
  - 自定义页面能渲染；
  - 隐藏的自定义页面不渲染；
  - 编辑模式下隐藏项显示为半透明。
- `editor/backend`：加载 8 个集合。
- 访客页面快照不变。
- 构建产物检查：dnd-kit 只出现在编辑器的 chunk 里，不在主包里。
- 在模拟模式下用浏览器验证：
  - 各页面拖拽，包括浮层、占位框和保存后的顺序；
  - 导航设置弹窗：拖动、隐藏、删除、恢复、新增页面和链接、编辑页面正文；
  - 手机尺寸。
