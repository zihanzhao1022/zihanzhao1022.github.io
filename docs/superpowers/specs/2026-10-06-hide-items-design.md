# 隐藏条目：设计文档

- 日期：2026-10-06
- 状态：设计已确认（用户选择"直接做并上线"）
- 基于：`2026-10-06-inline-edit-mode-design.md`

## 目标

在编辑弹窗里，"删除"按钮旁边增加"隐藏 / 取消隐藏"。隐藏的条目不删除，但访客看不到。

**不是保密功能**：仓库是公开的，隐藏条目仍然在 `content/*.json` 里。需要保密的内容应该删除。

## 适用范围

新闻、经历、论文、项目、报告、奖项。基本信息、简介、头像和联系方式不适用。

## 数据

- 列表条目增加可选字段 `hidden?: boolean`。
- 隐藏时写入 `"hidden": true`；取消隐藏时删除这个键，而不是写 `false`，保持 JSON 干净。
- 隐藏的条目保留在原来的位置，取消隐藏后完全复原。

## 访客

- **构建时剔除**：Vite 插件 `strip-hidden-content`（`enforce: 'pre'`）在 6 个列表文件被打包之前删掉 `hidden: true` 的条目，访客下载的页面代码里不包含它们。插件的纯函数放在 `lib/hiddenContent.ts`：`stripHiddenItems(json)`、`isContentListFile(id)`。
- **渲染时过滤**：`useVisibleItems(items)` 在非编辑状态下过滤掉隐藏条目。所有者关闭"编辑模式"开关时，也靠它看到和访客一致的页面。
- **年份分组**：在过滤后的列表上计算，所以全部条目都被隐藏的年份不会显示标题。
- **CV 页**：始终不显示隐藏条目，编辑模式下也一样，因为 CV 用于打印。

## 所有者（编辑模式开启时）

- 编辑器从 GitHub 读取的是完整内容，所以隐藏条目会照常显示，但整条变成半透明（`opacity-50`），标题旁有"已隐藏"标签。
- 编辑弹窗：
  - 底部是"删除 ｜ 隐藏 …… 取消 ｜ 保存"；已隐藏的条目这里显示"取消隐藏"，弹窗顶部还会提示"这一条目前对访客隐藏"。
  - 点"隐藏 / 取消隐藏"立即生效并提交，不需要二次确认。
  - 如果表单里有未保存的修改，先确认"放弃未保存的修改？"；隐藏操作本身不会带上表单里的修改。
- 排序弹窗：隐藏的条目也会列出，并标注"已隐藏"。

## 保存

- 新增内容操作 `{ kind: 'setHidden', collection, id, hidden }`：在 GitHub 上的最新版本中只修改这一条的 `hidden`，其他字段不动。
- 提交信息格式为 `content: hide <对象> "<标题>"` 或 `content: unhide <对象> "<标题>"`。

## 测试

- `editor/ops`：隐藏、取消隐藏、其他条目不受影响、`hidden` 键被删除；提交信息格式。
- `lib/hiddenContent`：剔除隐藏条目并保持顺序；只作用于 6 个列表文件，路径可以带查询参数或使用 Windows 分隔符。
- `views/hidden.test.tsx`：6 个页面在访客视角下不出现隐藏条目，编辑视角下出现且带"已隐藏"标签；CV 页两种情况下都不出现。
- 已有页面快照保持不变。
- 构建产物检查：临时把一条内容标记为隐藏后构建，确认 `dist` 里搜不到它的标题，检查完恢复。
- 在本地模拟模式下，用浏览器验证隐藏、取消隐藏、标签、开关预览和排序弹窗。
